# @ng-orbit/table

Headless Angular table controller for consumer-owned data, query intent, and rendering.

## Install

```bash
pnpm add @ng-orbit/table
```

## Docs

- Local: `pnpm demo` then open `http://127.0.0.1:4200/table/overview`
- Online: `https://christianrm-dev.github.io/ng-orbit/table/overview`
