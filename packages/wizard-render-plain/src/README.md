# @ng-orbit/wizard-render-plain

Internal placeholder package.

## Status

`@ng-orbit/wizard-render-plain` is not consumer-ready today. The package exists in the repo as
a future placeholder and does not expose a stable public API yet.

## What to use instead

- use `@ng-orbit/wizard` for the headless contract
- add `@ng-orbit/wizard-kit` when Angular forms should drive wizard validity
- use `@ng-orbit/wizard-render-material` or `@ng-orbit/wizard-render-daisy` for ready-to-install
  first UI layers
- use the docs host `Adapters` page for custom integration guidance

## Docs host

Run `pnpm demo` and open:
- `http://127.0.0.1:4200/wizard`
- `http://127.0.0.1:4200/adapters`
