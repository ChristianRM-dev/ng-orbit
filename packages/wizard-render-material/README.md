# @ng-orbit/wizard-render-material

Angular Material renderer for `@ng-orbit/wizard`.

## Install

```bash
pnpm add @ng-orbit/wizard @ng-orbit/wizard-render-material @angular/material @angular/cdk @angular/animations
```

## Docs

- Local: `pnpm demo` then open `http://127.0.0.1:4200/wizard/renders/material`
- Online: `https://christianrm-dev.github.io/ng-orbit/wizard/renders/material`
