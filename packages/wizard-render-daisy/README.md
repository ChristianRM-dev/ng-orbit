# @ng-orbit/wizard-render-daisy

DaisyUI-flavored renderer for `@ng-orbit/wizard`.

## Install

```bash
pnpm add @ng-orbit/wizard @ng-orbit/wizard-render-daisy
```

## Docs

- Local: `pnpm demo` then open `http://127.0.0.1:4200/wizard/renders/daisy`
- Online: `https://christianrm-dev.github.io/ng-orbit/wizard/renders/daisy`
