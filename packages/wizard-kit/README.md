# @ng-orbit/wizard-kit

Small Angular composition helpers for `@ng-orbit/wizard`.

## Install

```bash
pnpm add @ng-orbit/wizard @ng-orbit/wizard-kit
```

## Docs

- Local: `pnpm demo` then open `http://127.0.0.1:4200/adapters/overview`
- Online: `https://christianrm-dev.github.io/ng-orbit/adapters/overview`
