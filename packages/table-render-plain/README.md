# @ng-orbit/table-render-plain

Reference semantic renderer for `@ng-orbit/table`.

## Install

```bash
pnpm add @ng-orbit/table @ng-orbit/table-render-plain
```

## Docs

- Local: `pnpm demo` then open `http://127.0.0.1:4200/table/renders/plain`
- Online: `https://christianrm-dev.github.io/ng-orbit/table/renders/plain`
