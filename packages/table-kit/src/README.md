# @ng-orbit/table-kit

Internal placeholder package.

## Status

`@ng-orbit/table-kit` is not consumer-ready today. The package exists in the repo as a future
placeholder and does not expose a stable public API yet.

## What to use instead

- use `@ng-orbit/table` for the headless contract
- use `@ng-orbit/table-render-plain`, `@ng-orbit/table-render-material`, or
  `@ng-orbit/table-render-daisy` when you want a ready-to-install first UI layer
- use the docs host `Adapters` page for custom integration guidance

## Docs host

Run `pnpm demo` and open:
- `http://127.0.0.1:4200/table`
- `http://127.0.0.1:4200/adapters`
