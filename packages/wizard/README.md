# @ng-orbit/wizard

Headless Angular wizard controller for consumer-owned forms, navigation, and completion.

## Install

```bash
pnpm add @ng-orbit/wizard
```

## Docs

- Local: `pnpm demo` then open `http://127.0.0.1:4200/wizard/overview`
- Online: `https://christianrm-dev.github.io/ng-orbit/wizard/overview`
