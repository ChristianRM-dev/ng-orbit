# @ng-orbit/table-render-daisy

DaisyUI-flavored renderer for `@ng-orbit/table`.

## Install

```bash
pnpm add @ng-orbit/table @ng-orbit/table-render-daisy
```

## Docs

- Local: `pnpm demo` then open `http://127.0.0.1:4200/table/renders/daisy`
- Online: `https://christianrm-dev.github.io/ng-orbit/table/renders/daisy`
